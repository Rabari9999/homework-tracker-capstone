🏛️ System Architecture

🖥️ Frontend Tier

  • React 18 + Vite SPA
  • Nginx Alpine serving
  • 2 replicas (load balanced)

⚡ Backend API Tier

  • FastAPI (Python 3.12)
  • Async REST endpoints
  • HPA: 2-5 replicas
  • Non-root container (UID 10001)

🗄️ Data Persistence

  • PostgreSQL 16
  • SQLAlchemy ORM
  • Alembic migrations
  • Persistent Volume Claims
Client Browser → Ingress (Traefik) → Frontend Service → Backend Service → PostgreSQL

🔒 DevSecOps & Security Governance

Zero tolerance for high/critical vulnerabilities before any artifact is published.

Security DomainToolPolicyAction on Failure
SAST Bandit Medium / High severity Fails CI pipeline
SCA pip-audit & npm audit CVSS ≥ 7.0 Fails CI pipeline
Secrets Trivy FS Scanner Any detected secret Fails CI pipeline
Containers Trivy Image Scanner HIGH / CRITICAL CVEs Blocks GHCR publish
Runtime Non-root execution UID 10001 / non-root Enforced in Dockerfile
